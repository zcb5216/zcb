# AI一夏 超好玩：星际画猜总部（科幻大屏版）

这是一个面向课堂大屏和集体互动优化的你画我猜网页小游戏。

## 本次升级

- 欢迎词替换：状态栏改为活动欢迎词，不再使用旧提示句。
- 科幻官网风布局：全屏星空背景 + 大标题 Hero + 双栏控制台/创作台，页面随屏幕自适应。
- 画板强化：新增中笔、撤销、透明度、图形模式（直线/矩形/圆形）、星点喷洒工具。
- 保留公平机制：词语默认隐藏，仅通过 3 秒弹窗给小画家查看。

## 课堂玩法建议

1. 大屏投放页面，红蓝两队分组。
2. 小画家先点“给小画家看词（3秒）”。
3. 再点“开始”，45秒内作画抢答。
4. 猜对点“猜对+10”，或换词继续。
5. 每轮结束点“下一轮”，共6轮自动结算。
