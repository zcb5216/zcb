# AI一夏 超好玩：萌趣你画我猜（可爱风增强版）

这是一个适合班级集体参与的互动网页小游戏，主打**图文并茂 + 可爱风 + 高互动**。

## 新增亮点

- 🎨 内置画板：可直接鼠标/触屏作画。
- 🌈 可爱UI：糖果色、贴纸元素、卡片看板。
- 🧩 丰富互动：换词、倒计时、加分、换队、重置。
- 🐣 低门槛：不会AI也可通过画画参与表达。

## 玩法流程

1. 红蓝两队分组。
2. 每轮小画家看词（屏幕词语仅给小画家看）。
3. 点击“开始”进入 45 秒倒计时。
4. 猜对点“猜对+10”，可继续画下一个词。
5. 到时或完成后点“下一轮”，6轮后自动结算。

## 课堂建议

- 轮换小画家，让更多孩子上台。
- 规定“不能写字、不能说词，只能画”。
- 可配合欢呼口号增加节日氛围。
