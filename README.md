# AI一夏 超好玩：互动版你画我猜

这是一个适合班级集体参与的欢乐小游戏（类似“你画我猜”），主题为 AI。

## 核心玩法

- 红蓝两队对战。
- 每轮一位“小画家”看词作画，同队同学抢答。
- 每轮 45 秒，猜对 +10 分。
- 共 6 轮，最后比分高的队伍获胜。

## 使用步骤

1. 打开 `ai_yixia_game.html`。
2. 先让本轮小画家看屏幕词语。
3. 点击“开始本轮”计时。
4. 猜对点“✅猜对了”，可继续换词。
5. 时间到后点击“下一轮（换队）”。

## 现场组织建议

- 每轮轮换小画家，保证更多孩子参与。
- 画画规则：不能写字、不能读词，只能画。
- 可加“欢乐加分”：全班一起喊口号可额外 +5（老师手动记分）。
